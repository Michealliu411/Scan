# Project Guidance

This project is managed with GSD planning artifacts stored locally under `.planning/`.

Before implementing substantive changes, read:

- `.planning/PROJECT.md`
- `.planning/REQUIREMENTS.md`
- `.planning/ROADMAP.md`
- `.planning/STATE.md`

Planning docs are intentionally gitignored for this project. Keep implementation changes aligned with the active phase and update `.planning/STATE.md` when project direction changes.
