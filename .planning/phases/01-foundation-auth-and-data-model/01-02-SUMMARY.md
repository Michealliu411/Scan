## Decisions Made

- Used `qualifiedBarcodeKey String? @unique` so SQLite permits multiple unqualified records with `NULL` while preventing duplicate qualified records once Phase 2 writes the key.
- Kept `GET /production-lines` response deliberately narrow: `id`, `code`, and `name` only.
- Used `prisma migrate diff --from-empty --to-schema-datamodel ... --script` to create the migration SQL after `prisma migrate dev` failed with a schema-engine error in this environment.
