# PCR-20260713-production-quality-daily-report

## 1. 基本信息

- PCR 编号：PCR-20260713-production-quality-daily-report
- 提出日期：2026-07-13
- 提出人：生产质量现场
- 变更类型：新增查询报表 / 外部接口字段兼容 / 数据模型调整
- 影响模块：扫码解析、检验记录、查询分析、Excel 导出、Windows 更新包
- 当前状态：已实施并完成本地验证

## 2. 变更背景

现场现以 Excel 手工汇总座套生产质量日报，需要在系统中按自然月生成同结构的“一次下线合格率”日报，并完整展开全部不合格原因、支持 Excel 导出。上游生产订单接口新增“成品车型”和“成品品名”，可提供报表所需的车型和部件字段。

## 3. 变更范围

- 在查询分析增加质量日报页签和查询、导出能力。
- 新增一次下线日报汇总接口，按首次检验记录全局归属统计。
- 更新外部接口默认地址及车型、部件、原始产品名称字段映射。
- 为检验记录增加历史快照字段并执行兼容迁移。
- 复用查询用户、管理员权限与既有检验更正审计。

## 4. 不在范围

- 不新增车间、工序基础数据；两者固定为“缝纫”。
- 不向 ERP、MES、WMS 回写日报。
- 不补齐、推断或修复上游为空的车型、品名字段。
- 不改变日计划、扫码拦截、重复条码和返修流程规则。

## 5. 实施内容

实施前已确认《生产质量日报设计规格》。后续实现包括 Prisma 迁移、扫码接口映射、日报 API、查询页签、动态列、Excel 导出及自动化测试。

## 6. 数据库与数据影响

涉及新增检验记录快照字段及一次性兼容迁移。迁移保留所有既有检验记录、缺陷原因关联、操作日志、生产计划和基础数据；旧 `vehicleModel` 值复制至新 `productName` 后清空，避免旧产品名称被错误展示为车型。

## 7. 权限与审计影响

质量日报查询、导出限 `QUERY`、`ADMIN`；`INSPECTOR` 无访问权。查询与导出不新增日志；人工检验更正仍写既有操作日志，并影响日报当前统计结果。

## 8. 验证结果

已完成接口字段映射、兼容迁移、首检日报 API、查询页签、动态原因列和 Excel 导出。自动化验证通过：数据库模式校验、类型检查、lint、全量 API/前端测试（10 个 API 测试套件共 76 项、9 个前端测试文件共 64 项）及生产构建。浏览器以独立临时 SQLite 库验收了查询分析中的质量日报页签、默认年月、产线筛选、全部动态原因列、固定车间/工序、空结果文案和导出按钮。

## 9. 部署注意事项

发布前备份现场 `C:\scan\data\scan.db`。本次包含数据库迁移，现场更新不得使用 `-SkipDatabase`；更新包需写入新的 `SCAN_LOOKUP_URL` 默认值，并重启 ScanApi、ScanWeb。开发机既有 `apps/api/prisma/dev.db` 存在历史迁移漂移，验证未对其执行重置；现场应由发布脚本在备份后对实际数据库执行迁移。

## 10. 回滚方案

程序可回退至上一个发布包。新增字段为兼容字段，回退程序不删除现场数据；如需回退数据库展示逻辑，保留的 `productName` 可支持人工核查，禁止通过删除字段或覆盖数据库回滚。
