# PCR-20260615-production-order-lookup-empty-message

## 1. 基本信息

- PCR 编号：PCR-20260615-production-order-lookup-empty-message
- 提出日期：2026-06-15
- 提出人：现场试运行反馈
- 变更类型：缺陷修复 / 前端提示优化
- 影响模块：生产计划 - 下达日计划 - 查询订单
- 当前状态：已实现，待发布

## 2. 变更背景

现场使用水洗标签查询生产订单时，外部生产订单接口可正常连接，但部分标签返回“未查询到相关生产订单信息”。页面此前直接展示外部接口原始文案，容易让用户误判为系统接口连接异常或配置错误。

本次变更将“接口正常返回但无生产订单数据”的情况单独识别，并在页面展示更明确的业务提示。

## 3. 变更范围

- 生产计划页“下达日计划”区域的查询订单错误提示。
- 前端测试覆盖 `SCAN_LOOKUP_NOT_FOUND` 场景。

## 4. 不在范围

- 不修改外部接口地址、调用方式和鉴权方式。
- 不修改后端接口错误码。
- 不修改生产订单日计划规则、扫码校验规则和数据库结构。
- 不补录或修复上游系统缺失的生产订单数据。

## 5. 实施内容

- 在生产计划页错误处理逻辑中识别 `SCAN_LOOKUP_NOT_FOUND`。
- 页面提示调整为：`未查询到该标签对应的生产订单，请确认标签是否正确，或上游系统是否已生成该生产订单。`
- 保留 `Failed to fetch` 的网络/系统接口不可达提示，避免把“查无订单”和“接口连不上”混为一类。
- 新增前端组件测试，验证外部查询无订单数据时展示新的业务提示。

## 6. 数据库与数据影响

- 不涉及数据库表结构变更。
- 不涉及数据迁移。
- 不影响现场已形成的检验记录、生产计划、操作日志和基础数据。

## 7. 权限与审计影响

- 查询失败仍不写入业务数据。
