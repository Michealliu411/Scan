# PCR-20260716-quality-report-dashboard-adjustments

## 1. 基本信息

- PCR 编号：PCR-20260716-01
- 提出日期：2026-07-16
- 提出人：业务用户
- 变更类型：报表口径与展示优化
- 影响模块：查询分析、质量日报、统计看板、Excel 导出
- 当前状态：已实施，待发布

## 2. 变更背景

现场需要在质量日报中对照生产订单数量，同时避免已停用不合格原因继续占用动态列。统计看板的产线图表需使用业务人员熟悉的产线名称。

## 3. 变更范围

- 质量日报页面和 Excel 在“生产数量”前增加“生产订单数量”。
- 动态不合格原因列仅返回当前启用的原因。
- 统计看板产线柱状图 X 轴使用产线名称。

## 4. 不在范围

- 不修改首次检验口径、合格率公式或历史检验记录。
- 不删除已停用的不合格原因及其历史关联数据。
- 不新增数据库表或字段。

## 5. 实施内容

- API 按汇总行内的不同生产订单去重，汇总生产订单缓存中的订单数量。
- API 查询动态原因时增加 `isActive = true` 条件。
- 前端表格、空状态列数和 Excel 导出保持同一列序。
- 产线柱状图使用 `productionLineName` 作为 X 轴标签。

## 6. 数据库与数据影响

无数据库结构变更，无迁移。生产订单数量来自现有 `ProductionOrderCache.orderQuantity`；历史记录找不到对应缓存时显示 0。已停用原因的历史数据保留，仅不再生成报表动态列。

## 7. 权限与审计影响

无权限、数据权限或审计日志变更。

## 8. 验证结果

- `pnpm test`：API 10 个测试集、76 项测试通过；Web 9 个测试文件、64 项测试通过。
- `pnpm typecheck`：API 与 Web 通过。
- `pnpm lint`：API 与 Web 通过。
- `pnpm build`：API 与 Web 生产构建通过。
- 真实浏览器验证：产线柱状图 X 轴显示“A1缝纫线”；质量日报显示“生产订单数量”列及测试值 500；已停用原因 `UI-OLD` 未出现在动态列中。

## 9. 部署注意事项

不需要执行 Prisma 迁移或修改现场 `scan.db`。按既有 Windows 更新流程替换应用文件并完整重启 API 与 Web 服务。

## 10. 回滚方案

回退到变更前的应用版本并重启 API 与 Web 服务；由于无数据库变更，无需回滚数据。
