# PCR-20260615-production-plan-layout-adjustment

## 1. 基本信息

- PCR 编号：PCR-20260615-production-plan-layout-adjustment
- 提出日期：2026-06-15
- 提出人：现场试运行反馈
- 变更类型：前端界面调整
- 影响模块：生产计划 - 下达日计划
- 当前状态：已实现，待发布

## 2. 变更背景

生产计划页在现场使用时，“跨日复制”暂不需要暴露给用户；下达日计划查询后，订单信息继续堆在左侧会拉长输入区，影响页面扫描和录入的重点。现场确认采用左右分栏布局：左侧保留下达日计划查询，右侧显示查询到的生产订单信息和今日计划数下达操作。

## 3. 变更范围

- 隐藏生产计划页的跨日复制功能区。
- 调整下达日计划区域为四列网格：左侧面板占前两列，右侧订单信息占后两列。
- 查询订单成功后，在右侧展示生产订单信息。
- 将下达按钮文案调整为“下达订单”，并确保按钮文字为白色。

## 4. 不在范围

- 不删除后端跨日复制接口。
- 不修改生产计划数据库结构。
- 不修改生产计划下达、关闭、重新打开、产线调整和扫码校验规则。
- 不修改查询分析和检验扫描页面。

## 5. 实施内容

- 调整 `ProductionPlanPage` 渲染结构，移除跨日复制区块渲染。
- 将订单信息预览从左侧下达面板内移到右侧独立面板。
- 将“下达计划”按钮文案改为“下达订单”。
- 调整 CSS，使下达日计划面板右边框与上方第二个统计卡片右边框对齐。
- 增加前端测试，覆盖跨日复制隐藏、右侧订单信息和下达订单按钮。

## 6. 数据库与数据影响

- 不涉及数据库表结构变更。
- 不涉及数据迁移。
- 不影响现场已形成的生产计划、检验记录和操作日志。

## 7. 权限与审计影响

- 原有后端跨日复制能力仍保留，前端暂不暴露入口。
