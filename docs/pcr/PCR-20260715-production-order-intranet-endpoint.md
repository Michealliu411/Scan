# PCR-20260715-production-order-intranet-endpoint

## 1. 基本信息

- PCR 编号：PCR-20260715-01
- 提出日期：2026-07-15
- 提出人：现场用户
- 变更类型：生产配置修正
- 影响模块：生产订单解析接口、Windows 部署配置
- 当前状态：已实施，待生产环境更新配置

## 2. 变更背景

生产服务器 `192.168.1.144` 无法解析公网域名 `kdportal.kuangdacn.com`，导致生产计划查询和扫码解析无法调用生产订单接口。业务确认该接口在厂区内网的固定地址为 `192.168.1.151`，系统应统一使用内网地址。

## 3. 变更范围

- API 内置生产订单解析接口地址。
- 环境变量 `SCAN_LOOKUP_URL` 的部署取值。
- Windows 部署说明、操作手册及设计资料中的接口地址。
- 生产订单解析服务的单元测试。

## 4. 不在范围

- 不修改外部生产订单接口的协议、请求体或返回字段。
- 不修改扫描、生产计划和质量日报业务规则。
- 不修改数据库结构及历史业务数据。

## 5. 实施内容

生产订单解析接口统一为：

`http://192.168.1.151/ZTPDA/ServerCommand/getProductionOrderByShuiXiMai`

API 在缺少 `SCAN_LOOKUP_URL` 时也使用该内网地址；Windows 部署脚本继续保留现场已有配置，显式传入参数时以参数值为准。

## 6. 数据库与数据影响

本次不涉及 Prisma 模型、数据库迁移、初始化数据和历史数据处理，现场 `scan.db` 保持不变。

## 7. 权限与审计影响

不涉及用户权限、数据权限和审计日志变化。

## 8. 验证结果

- 单元测试验证配置地址和内置兜底地址均使用 `192.168.1.151`。
- 全仓文本检查确认运行代码、环境示例和部署资料不再使用公网域名。
- 生产环境需在更新配置后，从 `192.168.1.144` 验证内网接口返回。

## 9. 部署注意事项

在生产服务器将 `C:\scan\Scan\.env`、`C:\scan\Scan\apps\api\.env` 和 `C:\scan\Scan\apps\web\.env` 中的 `SCAN_LOOKUP_URL` 更新为内网地址，然后执行 `deploy-windows.ps1 -Mode Restart`。该命令会同时停止 `ScanApi`、`ScanWeb`，清理残留 Node 进程后再一起启动。无需执行数据库迁移，也不得覆盖 `C:\scan\data\scan.db`。

## 10. 回滚方案

恢复更新前的三个 `.env` 文件并执行 `deploy-windows.ps1 -Mode Restart`。本次无数据库变更，不需要数据回滚。
