# 生产订单日计划软件操作手册

## 1. 手册目的

本手册给现场使用人员说明软件层面的操作方法，重点说明：

- 如何通过扫描产品标签解析出生产订单。
- 如何按生产订单下达当天计划。
- 检验员扫码时如何看到订单和计划状态。
- 如何查询订单完成情况。

本手册不包含服务器部署、数据库更新和程序安装步骤。

## 2. 角色和入口

系统地址：

```text
http://192.168.1.144:8080
```

可使用功能：

| 角色 | 可见模块 | 本次相关操作 |
| --- | --- | --- |
| 查询用户 | 生产计划、查询分析 | 扫产品标签解析订单、下达计划、查询订单完成 |
| 管理员 | 检验扫描、生产计划、查询分析、基础数据 | 可执行全部相关操作 |
| 检验员 | 检验扫描 | 按已下达计划扫码检验 |

## 3. 重要概念

### 3.1 扫什么码

下达生产计划时，扫的是产品标签，也就是页面上的“水洗条码”。

不要手工扫或输入生产订单号。系统不是直接识别订单号，而是通过产品标签调用接口，解析出生产订单号、零件号、产品名称和订单数量。

### 3.2 订单从哪里来

软件把扫描到的产品标签发送给订单解析接口。

接口返回后，页面会显示：

- 生产订单
- 零件号
- 产品名称
- 订单数量

只有解析成功后，才能下达当天生产计划。

### 3.3 日计划控制什么

日计划控制的是当天该生产订单允许完成的合格数量。

- 合格扫码会占用计划完成数。
- 不合格扫码会记录在该订单下，但不占用合格完成数。
- 合格数达到今日计划数后，继续合格扫码会被系统拦截。

## 4. 每日下达生产计划

### 4.1 登录

1. 打开浏览器。
2. 访问：

```text
http://192.168.1.144:8080
```

3. 使用查询用户或管理员账号登录。
4. 登录后点击左侧菜单“生产计划”。

如果左侧没有“生产计划”，说明当前账号不是查询用户或管理员。

### 4.2 扫产品标签解析订单

在“生产计划”页面左上方找到“下达日计划”区域。

操作步骤：

1. 点击“水洗条码”输入框，让光标停在输入框内。
2. 用扫码枪扫描产品标签。
3. 如果扫码枪带回车，系统会自动触发查询；如果没有自动查询，点击“查询订单”。
4. 等待页面显示“生产订单信息”。

解析成功后，页面会出现：

```text
计划产线
生产订单
零件号
产品名称
订单数量
今日计划数
下达计划
```

确认“生产订单”和“产品名称”无误后，再继续下达计划。

### 4.3 下达今日计划

1. 在“计划产线”中选择当天实际生产这张订单的产线。
2. 在“今日计划数”中填写当天计划生产数量。
3. 默认情况下，系统会把今日计划数带成订单数量，可根据当天实际安排修改。
4. 点击“下达计划”。
5. 页面提示“生产计划已下达”后，计划生效。

下达成功后，下面的“生产计划列表”会出现该订单。

列表中可以看到：

- 状态：执行中或已关闭
- 生产订单
- 产品
- 订单数量
- 今日计划
- 合格 / 不合格
- 剩余
- 完成率
- 产线
- 操作

### 4.4 一个订单多产线或重复下达怎么办

同一天同一个生产订单可以下达到多条产线。

如果同一天同一个生产订单已经下达到同一条产线，再次对这条产线下达会提示冲突。此时不要重复下达，应在下方“生产计划列表”中找到该订单和产线，直接修改“今日计划”或“产线”并点击“保存”。

如果客户安排同一个订单当天在多条产线生产，可以分别选择不同“计划产线”下达多条计划。数量由用户自己控制，系统不自动校验多条产线合计是否超过订单数量。

## 5. 调整或关闭生产计划

### 5.1 查询已下达计划

在“生产计划列表”上方可以按条件查询：

- 计划日期
- 状态：全部、执行中、已关闭
- 生产订单

选择条件后点击“查询计划”。

### 5.2 调整今日计划数或产线

1. 在计划列表中找到目标生产订单。
2. 修改“今日计划”输入框中的数量，或修改该行“产线”下拉框。
3. 点击该行右侧“保存”。

注意：

- 已关闭计划不能修改。
- 今日计划数必须是正整数。
- 调整后，扫码完成控制立即按新计划数和新计划产线执行。
- 调整产线会写入操作记录。
- 如果目标产线已经有同订单当天计划，系统会阻止保存，需要直接调整目标产线那条计划。

### 5.3 关闭计划

如果当天不再继续生产某个订单：

1. 在计划列表中找到目标订单。
2. 点击该行右侧“关闭”。
3. 关闭后，该计划状态变成“已关闭”。

关闭后，检验员继续扫该订单的普通产品标签时，系统会拦截。

## 6. 跨日复制计划

如果今天计划和昨天或某一天相同，可以使用“跨日复制”。

操作步骤：

1. 在“生产计划”页面右上方找到“跨日复制”区域。
2. 选择“来源日期”。
3. 选择“目标日期”。
4. 点击“复制计划”。
5. 系统提示复制数量和跳过数量。

复制规则：

- 只复制来源日期中“执行中”的计划。
- 如果目标日期已经有同一个生产订单，系统会跳过，不会重复创建。
- 复制完成后，可以在目标日期计划列表里调整今日计划数。

## 7. 检验员扫码时如何看到订单

### 7.1 前提条件

检验员扫码前，查询用户或管理员应先完成当天生产计划下达。

如果没有当天计划，普通产品标签扫码会被拦截。

### 7.2 检验员扫码

1. 检验员登录系统。
2. 登录时选择当前产线。
3. 进入“检验扫描”页面。
4. 点击“条码”输入框。
5. 扫描产品标签。

解析成功后，“条码解析”区域会显示：

- 零件号
- 车型
- 生产订单
- 日计划状态
- 计划产线
- 已合格数 / 今日计划数
- 剩余数量
- 条码

示例：

```text
生产订单：PO-20260608-001
日计划状态：执行中
12 / 100
剩余 88
```

这表示该订单今天计划 100 件，目前已合格 12 件，还剩 88 件。

如果当前登录产线不是该订单计划产线，系统会拦截扫码提交。此时应让查询用户或管理员确认计划产线是否下达正确。

### 7.3 合格扫码

普通产品标签解析成功后，合格扫码会按系统当前流程提交。

提交成功后：

- 今日明细会新增检验记录。
- 该生产订单的合格完成数增加。
- 生产计划列表和订单完成查询中的完成数同步变化。

### 7.4 不合格扫码

不合格时：

1. 先点击“不合格”操作。
2. 选择缺陷原因。
3. 扫描产品标签。
4. 点击“提交”。

不合格记录会保留在该订单下，但不增加合格完成数。

## 8. 订单完成查询

查询用户或管理员可以查看订单完成情况。

操作步骤：

1. 点击左侧菜单“查询分析”。
2. 点击上方标签“订单完成”。
3. 选择“计划日期”。
4. 可选填“状态”或“生产订单”。
5. 点击“查询订单完成”。

页面会显示：

- 状态
- 生产订单
- 产品
- 订单数量
- 日计划数
- 合格数
- 不合格数
- 剩余数
- 完成率
- 产线

需要导出时，点击“导出Excel”，系统会生成 `订单完成.xlsx`。

## 9. 常见提示和处理

### 9.1 查询订单失败

可能原因：

- 扫的不是产品标签。
- 条码不属于可解析的水洗条码。
- 外部订单解析接口没有返回数据。
- 网络或接口服务异常。

处理方式：

1. 确认扫的是产品标签，不是订单号。
2. 重新扫描一次。
3. 如果多次失败，联系管理员检查订单解析接口。

### 9.2 提示缺少生产订单号或订单数量

说明接口返回了零件或产品信息，但没有返回生产订单号或订单数量。

处理方式：

1. 确认该产品标签在上游系统中是否已绑定生产订单。
2. 换同订单的另一张产品标签尝试。
3. 如仍失败，需要上游接口补充订单号和数量字段。

### 9.3 检验扫码提示没有当天计划

说明该生产订单当天还没有下达日计划。

处理方式：

1. 查询用户或管理员进入“生产计划”。
2. 扫该产品标签解析订单。
3. 下达当天计划。
4. 检验员重新扫码。

### 9.4 检验扫码提示计划已完成

说明该订单当天合格数已经达到今日计划数。

处理方式：

- 如果确实已完成，停止继续按该计划扫码。
- 如果现场需要追加计划，查询用户或管理员在“生产计划”中调大今日计划数并保存。

### 9.5 检验扫码提示订单未下达到当前产线

说明该生产订单当天计划下达到另一条产线，当前登录产线不能提交这张订单。

处理方式：

1. 确认检验员登录时选择的产线是否正确。
2. 如果登录产线选错，退出后重新选择正确产线登录。
3. 如果生产安排确实变更，查询用户或管理员进入“生产计划”，找到该订单，调整“产线”并保存。

### 9.6 扫码后页面没有自动查询

可能是扫码枪没有配置回车后缀。

处理方式：

1. 扫码后手动点击“查询订单”。
2. 或让现场设备人员把扫码枪配置为扫码后自动回车。

## 10. 日常推荐流程

每日开工前：

1. 查询用户或管理员登录。
2. 进入“生产计划”。
3. 扫当天要生产的产品标签。
4. 确认解析出的生产订单、产品名称、订单数量。
5. 填写今日计划数。
6. 点击“下达计划”。

生产过程中：

1. 检验员进入“检验扫描”。
2. 扫产品标签。
3. 查看生产订单和日计划状态。
4. 正常提交合格或不合格记录。

过程监督：

1. 查询用户或管理员进入“查询分析”。
2. 打开“订单完成”。
3. 按日期或生产订单查询完成情况。
4. 必要时导出 Excel。

收工或计划变更时：

1. 进入“生产计划”。
2. 对不再生产的订单点击“关闭”。
3. 对继续追加的订单调整今日计划数。
